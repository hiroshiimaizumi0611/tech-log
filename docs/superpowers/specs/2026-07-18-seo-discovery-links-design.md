# Google に記事を発見してもらうための内部リンク改善

## 結論

Google に登録済みの記事から未登録の記事へ、本文の流れに沿った内部リンクを追加する。あわせて `robots.txt` をビルド時に生成し、環境ごとに正しいサイトマップ URL を案内する。既存の関連記事ロジックは変更しない。

## 背景

2026年7月18日に Google Search Console を確認したところ、公開中の8記事のうち3記事がインデックス登録済みだった。残る5記事は「URL が Google に認識されていません」と表示された。公開中のサイトマップには全記事が含まれ、各記事の HTTP ステータス、canonical、H1、`BlogPosting` 構造化データ、robots の設定にも登録を妨げる問題はなかった。

現状の `robots.txt` はクロールを許可しているが、サイトマップの場所を記載していない。また、記事末尾の関連記事はカテゴリー、共通タグ、公開日の順で自動選定されるため、特定の記事へ意図的に読者とクローラーを案内する用途には向かない。

## 目的

- 登録済み記事から未登録記事へ、意味のある内部リンクを設ける
- Googlebot と他のクローラーへサイトマップの場所を明示する
- 読者が関連する解説へ自然に移動できるようにする
- 環境ごとの `SITE_URL` を維持し、テスト用 URL と本番 URL の混在を防ぐ

## 対象外

- 関連記事の自動選定ロジックの変更
- Search Console API との連携
- 外部サービスへの記事投稿や SNS 共有
- 記事タイトル、description、本文全体のリライト
- 独自ドメインへの移行

## 内部リンクの設計

リンクは既存の本文へ短い一文として加える。単独のリンク集は作らず、リンク先を読む理由が伝わるアンカーテキストを使う。

| 追加元 | リンク先 | 文脈 |
| --- | --- | --- |
| ChatGPT Sites | ChatGPT Work | Sites を含む成果物作成の役割を補足する |
| ChatGPT と Codex の Plugins | ChatGPT Work | Plugin と作業モードの役割を切り分ける |
| ChatGPT と Codex の Plugins | GPT-5.6 | 利用面とモデル選択を分けて確認する |
| Astro で技術ブログを構築 | Terraform drift | ブログで扱うインフラ運用記事へ案内する |
| Astro で技術ブログを構築 | HTTP QUERY | バックエンドと API 設計の記事へ案内する |
| Terraform drift | CloudFront VPC Origins 障害 | 変更管理と障害切り分けを混同しない実例として案内する |

同じリンクが自動の関連記事にも表示される場合があるが、本文リンクは説明の一部として残す。関連記事カードの選定結果は変更しない。

## robots.txt の設計

`public/robots.txt` を削除し、`src/pages/robots.txt.ts` から次の内容を生成する。

```text
User-agent: *
Allow: /
Sitemap: <SITE_URL>/sitemap-index.xml
```

Astro の `APIRoute` が受け取る `site` を使い、サイトマップ URL を組み立てる。`site` がない場合は不正な URL を生成せず、明示的にエラーにする。レスポンスの `Content-Type` は `text/plain; charset=utf-8` とする。

## 検証

### 単体・契約テスト

- robots エンドポイントが `site` を使って絶対 URL を生成する
- `site` がない場合のエラーを確認する
- 本文へ追加した内部リンクが公開中の実在記事へ解決する
- 下書きや外部 URL をリンク先へ含めない

### E2E

- `/robots.txt` が成功し、`Allow: /` と環境に対応する `Sitemap:` を返す
- 対象記事から追加したリンクを取得できる
- 既存の関連記事3件、前後記事、RSS、サイトマップの動作を維持する

### 最終確認

- `SITE_URL=https://example.invalid npm run verify`
- 本番ビルドで robots、記事、サイトマップの URL が同じオリジンを使うことを確認する

## 失敗時の扱い

- `site` が未設定ならビルドを失敗させ、サイトマップ URL の誤配信を防ぐ
- 内部リンク先が存在しなければテストを失敗させる
- Google のインデックス登録は保証しない。Search Console でクロールと表示回数を継続確認する

## 完了条件

- 6本の文脈付き内部リンクが本文に表示される
- `robots.txt` が環境に応じたサイトマップ URL を返す
- 全テストと本番ビルドが成功する
- 既存の関連記事ロジックと表示件数に変更がない
